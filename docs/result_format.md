# 재실 인원 서비스 v1 — 결과 형식

팀 2 Jetson에서 카메라로 공간의 재실 인원을 세어 10초마다 MQTT로 발행하고 REST로 조회할 수 있게 한다. 영상은 보드 밖으로 나가지 않고 숫자만 나간다.

## MQTT

브로커는 팀 2 Jetson의 mosquitto(포트 1883)다. 인원 토픽은 retain이라 구독하자마자 마지막 값을 받는다.

| 토픽 | 내용 | 주기 | QoS / retain |
| --- | --- | --- | --- |
| `aiot/space/<공간>/occupancy` | 공간별 재실 인원 (현재 `lab1`) | 10초마다 | 1 / 예 |
| `aiot/service/occupancy/status` | 서비스 상태 `online` / `offline` (비정상 종료 시 브로커가 offline 발행) | 시작·종료 때 | 1 / 예 |
| `aiot/space/<공간>/line` | 가상 선 통과 이벤트 (시험용 `line2.py`) | 통과 즉시 | 1 / 아니오 |

**`occupancy` 필드**

| 필드 | 형식 | 단위 | 뜻 |
| --- | --- | --- | --- |
| `ts` | 문자열 | ISO 8601 (KST) | 발행 시각 |
| `space` | 문자열 | — | 공간 이름 |
| `count` | 정수 | 명 | 최근 30초 중앙값 — 제어에는 이 값을 쓴다 |
| `raw` | 정수 | 명 | 마지막 1회 판정 값 (점검용) |
| `unit` | 문자열 | — | `명` |
| `window_s` | 정수 | 초 | 평활 창 길이 (30) |
| `stat` | 문자열 | — | 평활 방식 (`median`) |
| `age_s` | 실수 | 초 | 계산에 쓴 프레임의 나이. 5초를 넘으면 값을 믿지 않는다 |
| `camera` | 문자열 | — | `정상` / `끊김(재연결 중)` |
| `reconnects` | 정수 | 회 | 서비스 시작 후 카메라 재연결 횟수 |

```json
{"ts": "2026-11-03T08:53:10+09:00", "space": "lab1", "count": 0, "raw": 0, "unit": "명", "window_s": 30, "stat": "median", "age_s": 0.0, "camera": "정상", "reconnects": 0}
```

**`line` 필드**: `ts`(시각), `id`(추적 ID), `dir`(`IN` / `OUT`), `in`·`out`(누적 횟수).

```bash
mosquitto_sub -h <팀 2 Jetson 주소> -t 'aiot/space/+/occupancy' -v
```

## REST 조회

| 주소 | 돌려주는 것 |
| --- | --- |
| `http://<팀 2 Jetson>:8095/occupancy` | 공간별 최신 값 (MQTT `occupancy`와 같은 필드) |
| `http://<팀 2 Jetson>:8095/health` | 카메라별 상태·재연결 횟수, CPU·메모리·GPU 사용률, `saved_images`(저장한 이미지 수, 항상 0) |

## 갱신 주기와 주의점

- 사람 수는 1초마다 세고, 최근 30초 중앙값을 10초마다 발행한다. 사람이 들어오면 약 15초 뒤에 `count`에 반영된다.
- 인원 토픽이 30초 넘게 안 오거나 `status`가 `offline`이면 서비스가 멈춘 것이다.
- `camera`가 `끊김(재연결 중)`이거나 `age_s`가 5초를 넘으면 `count`는 오래된 값이다. 카메라는 2초마다 자동으로 다시 연결한다.
- 붐비고 가려지는 공간에서는 사람을 덜 센다(공개 데이터 시험에서 평균 31명 중 약 16명 누락). 냉난방·환기 제어에 쓸 때는 ‘있음/없음’ 판단을 우선하고, 정확한 인원이 필요하면 공간별 보정식을 적용한다.
- 개인정보: 영상·스냅샷·크롭을 저장하거나 내보내지 않는다. 로그에도 숫자와 상태만 남는다.
- 운영: systemd 서비스 `occupancy`(Restart=always), 카메라 비밀번호는 별도 환경 파일(chmod 600)에 보관한다.
